TAKE A LITTLE CALM WITH YOU

A pond on your page.

Copy the built files into your website. Add a canvas, then let the koi wander behind your content.

<canvas id="koi" aria-hidden="true"></canvas>
<style>
  #koi { position: fixed; inset: 0;
    width: 100%; height: 100%; z-index: -1; }
  body { isolation: isolate; }
</style>
<script type="module">
  import { KoiPond } from './stillwater.js';
  const pond = new KoiPond(
    document.querySelector('#koi'),
    { count: 7, interactive: false }
  );
  // Call pond.destroy() when unmounting.
</script>

No fonts, tracking, or runtime dependencies.
